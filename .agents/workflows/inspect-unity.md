# Inspect Unity

Use when understanding an existing Unity feature or project area.

1. Read relevant `/docs` files.
2. Inspect Unity editor state with MCP.
3. Inspect scene hierarchy and relevant GameObjects.
4. Inspect components/scripts/prefabs/assets involved.
5. Trace the current data/control flow.
6. Separate template/package behavior from Team Cero custom behavior.
7. Do not modify anything.
8. Report findings, uncertainties, and the smallest safe next step.
