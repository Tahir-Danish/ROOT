# Debug Unity

1. Reproduce the failure.
2. Capture the exact Console/build/device symptom.
3. Inspect the relevant GameObject/component/script/prefab.
4. Identify the smallest likely cause.
5. Make one logical change.
6. Recompile and re-test.
7. Avoid speculative multi-change fixes.
8. If unresolved, report evidence and the next diagnostic step.
