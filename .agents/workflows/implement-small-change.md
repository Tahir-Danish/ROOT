# Implement Small Unity Change

1. Restate the concrete goal and success criterion.
2. Inspect the current implementation.
3. Identify the smallest change.
4. Prefer existing Unity/XR systems over new code.
5. Modify only relevant assets/scripts/components.
6. Wait for compilation.
7. Inspect Console for errors.
8. Verify in Editor.
9. Build/test on Android if the change is AR/mobile-specific.
10. Report exactly what changed and what was verified.
