# XR Experiment

Use for learning/prototyping outside the core Cero vertical slice.

1. Define one learning question.
2. Isolate the experiment.
3. Reuse existing project systems where possible.
4. Change as little as possible.
5. Test on device when the question is about AR behavior.
6. Record the result in `/docs/EXPERIMENT_LOG.md` only when explicitly asked.
7. Keep or remove the experiment intentionally; do not let temporary assets become accidental architecture.
