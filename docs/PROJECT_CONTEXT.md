# Team Cero — Project Context

## Project

- Team: Team Cero
- Pilot: VIT Vellore
- Context: GEG XR Hackathon
- Internal deadline assumption: 5 September 2026 until organizer clarification

## Problem

Create an AR + AI-powered Field Intelligence App for Native Plants that uses a smartphone as a biodiversity field assistant, bridging scientific knowledge and public engagement.

## Intended experience

Encounter → Scan → Identify → Understand → Explore → Ask → Conserve

A user encounters a supported plant, scans it, receives an identification and confidence result, sees contextual information in AR, explores ecological/conservation information, and can ask a Botanical Guide questions.

## Team roles

- XR / overall lead: AR/XR, product coherence, technical direction, integration, final demo integration.
- S: UI/UX, app flows, software, APIs/backend, integration.
- P: dataset, computer vision, training/evaluation, inference, confidence/failure handling.
- M: plant research, native status, ecological/conservation information, source verification, image/reference collection.

## Hardware

Current practical direction is Android-first because most of the team can directly test Android. iOS is secondary unless useful later.

## Working philosophy

- Learn only what the project needs.
- Prototype a narrow vertical slice before expanding.
- Avoid overengineering.
- AI accelerates implementation; humans verify functionality.
- Complete before clever.
