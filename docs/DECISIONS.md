# Team Cero — Decisions

| Decision | Status | Reason |
|---|---|---|
| Unity for XR | Decided | Mobile AR fit, AR Foundation alignment, rapid iteration |
| Android-first | Decided | Most direct team testing coverage |
| AR Foundation | Decided | Core handheld AR foundation and organizer alignment |
| Use existing Mobile AR Template systems | Preferred | Reduces code and delivery risk |
| ML/XR loosely coupled | Decided | Parallel development and simpler integration |
| MCP is development infrastructure | Decided | Accelerates editor inspection/automation; not a shipped feature |
| Complete before clever | Decided | Short deadline and high integration risk |
| Native app for AR experience | Working direction | More controlled handheld AR runtime; web can support presentation/distribution |
| Optional features are deferred | Decided | MVP first |

## Reopen a decision only when

- new evidence shows a blocker;
- the current approach materially threatens delivery;
- organizer requirements change.

Do not reopen settled decisions based only on general preference or novelty.
