# Team Cero — Product Specification (MVP)

## Organizer-defined requirements

### AI plant identification
- User scans a plant with device camera.
- Computer-vision model identifies it.
- Minimum supported coverage: 7 plants.

### AR species visualization
Information must appear in the camera view using AR:
- Scientific Name
- Common Name
- Plant Family
- Native / Native Region
- Ecological Importance
- Conservation Status

### AI Botanical Guide
The assistant should:
- explain plant characteristics;
- explain ecological importance;
- answer conservation questions;
- educate users about local biodiversity.

### Conservation awareness
The product should:
- explain why native species matter;
- highlight threats;
- share conservation best practices;
- suggest ways individuals can contribute.

### Prototype / validation
- Working, platform-agnostic prototype.
- At least 5 users provide feedback.
- Record observations/learnings and improvements.

### Optional innovation
Potential bonus features, not MVP:
- rare/endangered highlighting;
- gamified discovery;
- offline AI;
- location-based biodiversity insights;
- species comparison/recommendation.

## AR quality test

Ask: **What does AR add that a normal mobile webpage would not?**

AR should connect information contextually to the real plant, not merely display a generic UI on top of a camera feed.
