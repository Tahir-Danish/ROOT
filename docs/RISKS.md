# Team Cero — Risk Register

| Risk | Severity | Mitigation |
|---|---|---|
| XR learning/deployment | High | Small device-tested experiments; reuse template |

| Short timeline | High | Vertical slice first; defer optional features |
| Scope creep | High | MVP boundary and decision log |
| Agent overreach | Medium/High | Read-only inspection rules; minimal-change workflow |
| Stale project documentation | Medium | Docs describe intent; MCP describes live implementation |
| Mobile performance/build size | Medium | Test on real device and profile only when needed |
